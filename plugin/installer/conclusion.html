neuropolis установлен

Переоткройте DAW, чтобы обновить список плагинов.

Logic Pro
Software Instrument → MIDI FX → Audio Units → Neuropolis → neuropolis.

После neuropolis выберите инструмент, который будет играть сгенерированные ноты.

Другие DAW
Выберите neuropolis в списке VST3 и направьте его MIDI-выход на инструмент.
